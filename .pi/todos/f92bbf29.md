## What

End-to-end validation: build, test, and verify the complete Go project works correctly.

## Steps

1. **Run all unit tests**: `go test ./...` — verify all ported tests pass (config, discover, syncplan, gitmodules)

2. **Build the binary**: `go build -o gitjuggling .` — verify it compiles cleanly

3. **Manual smoke test — exec command**:
   ```bash
   ./gitjuggling exec -d 2 -- git status
   ```
   Run in a directory with multiple git repos. Verify:
   - TUI shows progress bar
   - Summary shows succeeded/failed counts
   - Exit code is correct

4. **Manual smoke test — sync command** (dry-run):
   ```bash
   ./gitjuggling sync --dry-run
   ```
   Verify:
   - Config loads from `UserConfigDir/gitjuggling/config.yaml`
   - TUI shows loading phase with spinners
   - Plan review shows update/move/clone actions
   - Dry-run messages appear correctly

5. **Verify config migration**: Create a YAML config file matching the old TOML format and confirm it parses correctly

6. **Run `go vet ./...`** and fix any issues

7. **Optionally** add a `justfile` with common commands:
   - `build`: `go build -o gitjuggling .`
   - `test`: `go test ./...`
   - `check`: `go vet ./...`
   - `install`: `go install`
