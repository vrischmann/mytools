## What

Port `gitjuggling/src/gitmodules.rs` to `internal/gitmodules/gitmodules.go`.

## Source

Rust: `gitjuggling/src/gitmodules.rs` — custom parser for `.gitmodules` files (TOML-like format with `[submodule "name"]` sections).

## Target

Go: `internal/gitmodules/gitmodules.go` + `internal/gitmodules/gitmodules_test.go`

## Details

### Structs

```go
type GitSubmodule struct {
    Name   string
    Path   string
    URL    string
    Branch string // optional
}

type GitModules struct {
    Submodules []GitSubmodule
}
```

### Functions

- `Parse(input string) (*GitModules, error)` — parse the `.gitmodules` file content:
  1. Find `[submodule "<name>"]` sections
  2. Parse key=value pairs within each section: `path`, `url`, `branch`, etc.
  3. Stop a section when a new `[` is encountered or EOF

- `(gm *GitModules) Contains(path string) bool` — check if any submodule has the given path

### Parsing notes

The `.gitmodules` format is TOML-like. We can either:
- Write a custom parser (like the Rust version) — simple since the format is very regular
- Use a TOML library — but it's an extra dependency for just this one use case

Recommendation: write a custom parser to match the Rust approach. The format is straightforward:
```
[submodule "foobar"]
    path = foo
    url = git@github.com:foo/bar.git
```
