## Details

### Types

```go
type ActionType int

const (
    ActionUpdate ActionType = iota
    ActionMove
    ActionClone
)

type Action struct {
    Type         ActionType
    Repo         *remote.RemoteRepo
    LocalPath    string   // set for Update
    CurrentPath  string   // set for Move
    ExpectedPath string   // set for Move, Clone
}
```

### Functions

- `ClassifyRepo(repo *remote.RemoteRepo, ws *config.Workspace) string` — return expected local path based on rules:
  1. `is_fork` → `rules.forks` (if configured)
  2. `is_archived` → `rules.archived` (if configured)
  3. default → `rules.base`
  - Final path: `<basedir>/<owner>/<name>`

- `BuildPlan(remoteRepos []*remote.RemoteRepo, local *discover.LocalRepos, ws *config.Workspace) []Action` — for each remote repo:
  - Look up by clone URL in local repos
  - If found at expected path → `ActionUpdate`
  - If found at wrong path → `ActionMove`
  - If not found → `ActionClone`
