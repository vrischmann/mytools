## What

Create the new Go project with the full directory layout and all dependencies declared.

## Steps

1. Create `~/dev/perso/projects/gitjuggling-go/`
2. `go mod init github.com/vrischmann/gitjuggling`
3. Create the full directory structure:
   ```
   gitjuggling-go/
   ├── main.go              (minimal main(), just calls cmd.Execute())
   ├── go.mod
   ├── cmd/
   │   └── root.go          (skeleton: cobra root with no subcommands yet)
   ├── internal/
   │   ├── config/
   │   ├── discover/
   │   ├── remote/
   │   ├── syncplan/
   │   ├── execute/
   │   ├── prune/
   │   ├── gitmodules/
   │   └── tui/
   ```
4. Add all dependencies to `go.mod`:
   - `github.com/charmbracelet/bubbletea`
   - `github.com/charmbracelet/bubbles`
   - `github.com/charmbracelet/lipgloss`
   - `github.com/spf13/cobra`
   - `gopkg.in/yaml.v3`
   - `golang.org/x/sync`
5. Run `go mod tidy` to resolve transitive deps
6. Verify it compiles with `go build ./...`

## Acceptance

- `go build ./...` succeeds with no errors
- All package directories exist with at least placeholder files
