## What

Port `gitjuggling/src/prune.rs` to `internal/prune/prune.go`.

## Source

Rust: `gitjuggling/src/prune.rs` — find orphan repos (local repos with no upstream match), optionally remove them.

## Target

Go: `internal/prune/prune.go`

## Details

### Structs

```go
type OrphanRepo struct {
    Path string
    Name string
}

type PruneResult struct {
    Name    string
    Path    string
    Success bool
    Message string
}
```

### Functions

- `FindOrphans(local *discover.LocalRepos, remoteRepos []*remote.RemoteRepo) []*OrphanRepo` — build a set of normalized remote URLs, check each local repo's remote URLs against it. Repos with no match are orphans.

- `PruneOrphans(orphans []*OrphanRepo, dryRun, interactive bool, confirmFn func(string) bool) []*PruneResult` — iterate orphans:
  - If dry-run → return "would remove" message
  - If interactive → call `confirmFn` to ask user; skip if declined
  - Otherwise → `os.RemoveAll(path)`

### Interactive callback

Same pattern as execute: `confirmFn func(prompt string) bool` callback so TUI layer provides the Bubbletea dialog.

### URL normalization

Reuse the same normalization logic as `discover.normalizeURL()`. Either import and call it, or have a shared utility. The Rust version duplicates the logic — in Go we should call `discover.NormalizeURL()` directly.

### No tests to port

Rust code has no unit tests for prune.
