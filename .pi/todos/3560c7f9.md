## What

Create `cmd/root.go`, `cmd/sync.go`, and `cmd/exec.go` with Cobra, wiring up all the internal packages.

## Target

Go: `cmd/root.go`, `cmd/sync.go`, `cmd/exec.go`

## Details

### `cmd/root.go`

- Define root command: `gitjuggling`, description "Repository sync and git command runner"
- Disable version flag (match Rust behavior)
- Register `sync` and `exec` subcommands
- `Execute()` function called from `main.go`

### `cmd/sync.go`

Subcommand: `gitjuggling sync [workspace] [flags]`

Flags:
- `--config string` — path to config file (optional)
- `--dry-run` — show what would be done
- `--interactive` (default `true`, accepts `--interactive=false`)
- `--prune` — prune local repos with no upstream match
- `-c, --concurrency int` (default `2`)

Positional arg: optional workspace name

Run function orchestration:
1. Load config (`config.LoadDefault()` or `config.LoadFrom()`)
2. Resolve workspace
3. Fetch GitHub repos (`remote.FetchGitHubRepos`)
4. Fetch Forgejo repos (`remote.FetchForgejoRepos`)
5. Dedup (`remote.DedupRepos`)
6. Discover local repos (`discover.Discover`)
7. Build plan (`syncplan.BuildPlan`)
8. Execute actions (`execute.ExecuteActions`)
9. Optionally prune (`prune.FindOrphans` + `prune.PruneOrphans`)
10. Print summary

For now, wire the logic with simple `fmt.Println` output. The Bubbletea TUI will replace this in a later task.

### `cmd/exec.go`

Subcommand: `gitjuggling exec [flags] -- <git args...>`

Flags:
- `-d, --depth int` (default `3`)
- `-c, --concurrency int` (default `2`)
- `-v, --verbose` — show output from all repos, not just failures

Trailing args: git command to execute (use `cobra.MinimumNArgs(1)`)

Run function:
1. Walk for repos using `filepath.WalkDir` (similar to discover but simpler — just find `.git` dirs, skip submodules)
2. Execute git command in each repo with bounded concurrency
3. Collect results, partition into succeeded/failed
4. Print output (verbose mode shows all, otherwise only failures)
5. Print summary: counts + elapsed time
6. Exit code 1 if any failures

For now, use simple `fmt.Println` output. Bubbletea TUI comes later.

### Exit codes

- `exec`: exit 1 if any command failed
- `sync`: exit 0 always (matches Rust behavior)
