## What

Port `gitjuggling/src/config.rs` to `internal/config/config.go`.

## Source

Rust: `gitjuggling/src/config.rs` — structs `Config`, `Workspace`, `Rules` with TOML parsing, default path `~/.config/gitjuggling/config.toml`.

## Target

Go: `internal/config/config.go` + `internal/config/config_test.go`

## Details

### Structs

```go
type Config struct {
    DefaultWorkspace string               `yaml:"default_workspace"`
    Workspaces       map[string]*Workspace `yaml:"workspace"`
}

type Workspace struct {
    Root            string   `yaml:"root"`
    GitHubOwners    []string `yaml:"github_owners"`
    ForgejoURL      string   `yaml:"forgejo_url"`
    ForgejoUser     string   `yaml:"forgejo_user"`
    ForgejoTokenCmd string   `yaml:"forgejo_token_cmd"`
    LocalScanRoot   string   `yaml:"local_scan_root"`
    Rules           Rules    `yaml:"rules"`
}

type Rules struct {
    Base     string `yaml:"base"`
    Forks    string `yaml:"forks"`
    Archived string `yaml:"archived"`
}
```

### Functions

- `LoadFrom(path string) (*Config, error)` — read file, unmarshal YAML
- `LoadDefault() (*Config, error)` — use `os.UserConfigDir()` to resolve `<configdir>/gitjuggling/config.yaml`
- `(c *Config) GetWorkspace(name string) (*Workspace, error)` — resolve by name or fall back to `DefaultWorkspace`
- `(w *Workspace) LocalScanRoot() string` — return `LocalScanRoot` if set, else `Root`

### Config format changes

Switch from TOML to YAML. Example equivalent config:
```yaml
default_workspace: personal
workspace:
  personal:
    root: /home/user/dev
    github_owners: [vrischmann]
    forgejo_url: https://git.example.com
    forgejo_user: vincent
    forgejo_token_cmd: "op read 'op://vault/item/field'"
    rules:
      base: /home/user/dev/repos
      forks: /home/user/dev/forks
      archived: /home/user/dev/archived
  work:
    root: /home/user/work
    github_owners: [MyOrg]
    rules:
      base: /home/user/work/repos
```

### Tests to port

- `test_parse_minimal_config` — parse minimal YAML, check struct fields
- `test_parse_full_config` — parse full YAML with all fields populated
- `test_get_workspace` — explicit name, default fallback, missing workspace error
- `test_local_scan_root_default` — falls back to Root
- `test_local_scan_root_override` — uses LocalScanRoot when set
